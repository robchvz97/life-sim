# Life Sim v17.1.5 — Clean Observatory

Esta revisión no cambia las leyes del mundo ni el comportamiento de los organismos.

Su objetivo es hacer mucho más fácil saber si el universo está funcionando correctamente.

## Panel principal

El HUD muestra por defecto solo 14 métricas.

### Salud del mundo

- Población
- Individuos fértiles
- Balance poblacional
- Energía promedio
- Salud promedio
- Riesgo demográfico

### Evolución y cultura

- Generación máxima
- Mayor asentamiento
- Comprensión comunicativa
- Procedimientos tecnológicos
- Agua almacenada

### Sociedad

- Grupos sociales
- Relaciones recíprocas
- Intercambio regional

Estas métricas son suficientes para revisar rápidamente:

- supervivencia;
- reproducción;
- estabilidad energética;
- avance generacional;
- cultura;
- tecnología física;
- organización social.

## Diagnóstico avanzado

Todos los contadores anteriores siguen existiendo.

No se eliminó ningún dato.

El botón **Diagnóstico avanzado** despliega:

- nacimientos y muertes absolutos;
- alimentos y materiales;
- cerebro y topologías;
- física Rapier;
- combustión;
- recipientes;
- lluvia;
- marcas;
- dialectos;
- imitaciones;
- procedimientos;
- genealogía;
- persistencia;
- y el resto de métricas técnicas.

Así podemos abrirlo únicamente cuando detectemos un problema.

## Historia del mundo

El panel **Historia del mundo** continúa igual.

Es especialmente útil porque registra acontecimientos significativos sin llenar el HUD de contadores.

## Simulación

La mecánica de v17.1.4 se conserva:

- lluvia;
- agua transportable;
- recipientes;
- interacción con el estanque;
- procedimientos contextuales;
- reproducción sexual;
- cultura;
- tecnología física;
- memoria social;
- geografía regional.

v17.1.5 es principalmente una revisión de interfaz/observabilidad.
